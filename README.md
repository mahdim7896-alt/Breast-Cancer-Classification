# Breast Cancer Classification

This project uses machine learning to classify breast cancer tumors as benign (B) or malignant (M).

## Dataset
The dataset contains features computed from breast cancer images.

## Model
Logistic Regression was used for classification.

## Features
- Data preprocessing
- Label encoding (M → 1, B → 0)
- Feature normalization
- Train-test split
- Model evaluation using accuracy and classification report

## Requirements
Install the required libraries using:

```bash
pip install -r requirements.txt
```

## How to Run
Run the project with:

```bash
python main.py
```
